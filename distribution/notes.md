## 解压即用

下载 MTG_Cube_Builder-Windows-x64-20261027-r5.zip，完整解压后双击 **启动Cube助手.exe**。Windows 10/11 64 位；内置 Python、Java、Forge 与卡牌快照，无需自行安装环境。离线可构筑、审计、轮抓与实战，AI 由每位用户自行配置。

发布包不含开发者账号、凭据、个人牌表、偏好、对局、测速、模型或生成缓存。升级前可备份个人数据，在独立目录完整解压新版；恢复旧版也在独立目录解压，使用各自生成的缓存。GitHub 的 Source code 为开发源码，普通玩家请选择 Windows 便携包。
