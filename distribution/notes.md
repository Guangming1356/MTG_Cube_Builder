## 解压即用

下载 MTG_Cube_Builder-Windows-x64-20261027-r2.zip，完整解压后双击 **启动Cube助手.exe**。Windows 10/11 64 位；内置 Python、Java、Forge 与卡牌快照，无需自行安装环境。离线可构筑、审计、轮抓与实战，AI 由每位用户自行配置。

发布包不含开发者账号、凭据、个人牌表、偏好、对局、测速或模型。旧牌表不会自动删牌；采用新偏好审计时会提示需要处理的 {C} 牌。升级前可备份个人数据，在独立目录完整解压新版。GitHub 的 Source code 为开发源码，普通玩家请选择 Windows 便携包。
