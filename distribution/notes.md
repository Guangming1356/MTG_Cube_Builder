## 本版 · 0.2.3 原始实战证据校验

- 修正无正文 Java 异常可能被误记为正常胜利的问题；保留异常类型，继续区分整局时限与单次 AI 决策超时。
- 缓存读取与历史学习重新核验原始日志的胜负及提交座位，排除不一致标签；历史文件与比较记录保留。
- 实战模型升级为 activity-5。旧模型需重新学习，可复用经过新核验的真实历史对局；采用门槛保持不变。报告增加证据不一致的排除数量。
- 最近实战报告同时核对当前牌库，正确说明旧报告与重新学习状态。
- 完整回归 464 项通过；180 份既有原生日志分类、胜者全部保持一致（179 正常、1 异常）。新增校验 CPU 约 0.78 毫秒/局，这是所选日志上的成本测量。

本机重新学习 698 局、235 组独立牌组，其中最终测试 40 组，误差改善约 2.1%，未过原有采用门槛，继续固定评分。小样本机器人研究不能证明真人娱乐性或全部色组均衡。相关原始数据、模型、账号和个人配置不包含在发布包中。

继承 0.2.2 的工作区恢复、依赖显示、并行内存提示，以及个人偏好模型版本/牌库/玩法校验。角色识别、固定质量消融和配对发包研究未通过完整门槛，不更换默认构筑或减少正式对局预算。方法与限制见包内 cube_ai/docs/OPTIMIZATION_20261023.md。

## 使用方法

下载 MTG_Cube_Builder-Windows-x64-20261023-r2.zip，完整解压后双击 **启动Cube助手.exe**。Windows 10/11 64 位，内置 Python、Java、Forge 与卡牌快照，无需安装环境。离线即可构筑、审计、轮抓与实战，AI 由各用户自行配置。

发布前在独立干净 Windows 环境验证启动、原生名称、证据判定、轮抓、暂停/继续、退出保护和重启恢复。发布包清除凭据、账号、个人牌表、偏好、对局、测速及模型。

更新前可备份个人牌表和数据，在单独目录解压新版。GitHub 的 Source code 为开发源码，普通玩家请下载上述 Windows 便携包。
