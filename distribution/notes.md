## 解压即用

下载 MTG_Cube_Builder-Windows-x64-20261114-r2.zip，完整解压后双击 **启动Cube助手.exe**。Windows 10/11 64 位；内置 Python、Java、Forge 与卡牌快照。离线可构筑、审计、轮抓与实战，AI 由用户自行配置。

发行包排除开发者账号、凭据、个人牌表、对局、模型和生成缓存。升级前可备份个人数据，在独立目录完整解压新版。GitHub 的 Source code 为开发源码，普通玩家请选择 Windows 便携包。
