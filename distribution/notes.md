## 本版更新 · 0.2.1

- 修复部分原生已支持的同名替代牌被误判为不支持的问题，覆盖精确匹配原生数据中的 182 个正面名称。导出保留牌名，对局日志映射回选入的牌。
- 名称清单按哈希校验，原生 JAR、牌张脚本或系列数据改变时停止启用；清单缺失或篡改时旧缓存也会失效，打包检查直接失败。
- 新增较小内存的 Parallel GC 测速配置。108 次固定原生比较的结果与事件一致；本机相较此前采用配置，双进程耗时约少 5.4%、峰值私有内存约少 15%。其他电脑需自行测速，空闲内存保护继续控制并行数。
- 测速增加实际后端一致性检查，静默回退结果不支持自动采用配置；API 支持只预览推荐结果。
- 组牌对照可选“保留已选终结牌”，报告显示实际方式与限制。216 场对照的整体门槛未通过，默认仍使用单卡质量优先。
- 新增原生卡名清单的公开重建与检查工具，组牌研究保存对应源码和名称清单。
- 完整源码回归 341 项通过，另外验证名称清单与缓存失效路径。

详细实验、失败门槛、测试脚本中断及未重跑的恢复记录见包内 `cube_ai/docs/OPTIMIZATION_20261022.md`。固定机器人用例不代表全部牌张、人类娱乐性或其他机器的收益。

## 解压即用

下载 `MTG_Cube_Builder-Windows-x64-20261022.zip`，完整解压后双击 **启动Cube助手.exe**。支持 Windows 10/11 64 位，内置 Python、Java、Forge 和卡牌快照；无需自行安装环境。

发布前使用独立干净 Windows 环境检查离线启动、原生名称清单、轮抓、暂停/继续、进行中退出保护与重启结果恢复。包内清除本机账号、凭据、个人牌表、偏好、对局、测速及模型。各用户可自行连接 AI；没有 AI 也能本地构筑与实战。

GitHub 的 `Source code` 是开发源码；普通玩家请下载上面的 Windows 便携包。更新前可备份自己的牌表和个人数据，再把新版解压到单独目录。
