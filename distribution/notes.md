## 构筑研究结果

两批共检查 60 套牌表、1,200 桌轮抓。新的抓牌/装备资源识别候选随后完成 180 局 Forge 对照：179 局正常，一局 AI 单次行动选择超时按异常保留，未补打。候选未通过行动与终结的不劣门槛，默认生成器继续使用现有本体；没有把静态标签修正宣传为实战提升。研究数据未加入评分训练。

方法、失败门槛、缓存与 CPU 测量见包内 `cube_ai/docs/ROLE_ONTOLOGY_STUDY.md` 和 `cube_ai/docs/OPTIMIZATION_20261023.md`。小样本机器人对局不证明人类娱乐性或全部色组均衡。

## 解压即用

下载 `MTG_Cube_Builder-Windows-x64-20261023.zip`，完整解压后双击 **启动Cube助手.exe**。支持 Windows 10/11 64 位，内置 Python、Java、Forge 和卡牌快照，无需自行安装环境。

发布前使用独立干净 Windows 环境检查启动、原生名称清单、轮抓、暂停/继续、退出保护及重启恢复。发布包清除本机账号、凭据、个人牌表、偏好、对局、测速和模型。各用户自行连接 AI；没有 AI 也可本地构筑与实战。

GitHub 的 `Source code` 是开发源码。普通玩家请下载 Windows 便携包。更新前可备份个人牌表和数据，把新版解压到单独目录；移动目录或更新牌库后，偏好模型可能需要用保留的比较重新训练。
