## 0.2.17 — 轮抓更易复现，批量统计减少内存

- 抓牌与准备度测试使用分开的随机状态，改变准备度抽样次数不再改变后续桌的牌包、牌池和组牌。
- 每手只抽取起手加前四回合会观察的 11 张牌，费用规则保持 printed-cost-2。固定牌组的准备度计算耗时约减半；同一批实际轮抓的受控 200 桌流程中位耗时由 2.203 秒降至 1.995 秒，约减少 9.5%。
- 逐桌累计报告，500 桌汇总阶段的 Python 分配峰值由 9.81 降至 0.32 MiB，完整汇总结果一致。具体测量范围见优化报告。
- 724 项回归、90 副固定牌组导出及默认 Forge 入口 9 局实战检查通过；九局均正常完成，不据此宣称胜率提升。
- 报告记录采样版本和抽样量。旧版非零抽样下相同种子的后续牌桌会与新版不同；个人历史牌组、日志、配置和模型保留。

发行包排除开发者账号、凭据、个人牌表、对局、模型和生成缓存。升级前可备份个人数据，在独立目录完整解压新版。GitHub 的 Source code 为开发源码，普通玩家请选择 Windows 便携包。
