## 0.2.19 — 更准确地估算部分特殊施放费用

- 轮抓曲线和起手估算识别部分额外法术力费用、waterbend 与资源或法术力二选一费用。牌面法术力值不变，详情解释估算的假设。
- 完整测试 759 项通过；30 桌轮抓及 36 局 Forge 对局作为有限验证，不能证明总体胜率提升。
- 旧版个人偏好模型会保留，但不兼容时不会自动使用；可用已有反馈重新训练。

## 解压即用

下载 MTG_Cube_Builder-Windows-x64-20261116.zip，完整解压后双击 **启动Cube助手.exe**。支持 Windows 10/11 64 位；离线可构筑、审计、轮抓与实战，AI 由用户自行配置。升级前建议备份个人数据，在独立目录解压新版。GitHub 的 Source code 为开发源码，普通玩家请选择 Windows 便携包。
