# 看懂并复现对局异常

入口：打开实战记录或组牌对照，在结果中展开 **复现异常：比较常驻与原生入口**，选择一局。诊断也可在最近任务中重新打开。

助手会复制原来的牌组文件，保持顺序与随机种子，依次通过常驻入口和 Forge 原生命令入口各运行一局。最多同时一个引擎，不修改 Cube，不覆盖原结果，不使用比赛缓存，也不把诊断重复局加入学习样本。可在任务区暂停或结束。

## 结果说明

- **两种入口出现相同异常症状**：证据更支持 Forge/AI 相关问题，不能只归因于常驻桥接；仍未定位具体卡牌或声称已修复。
- **两种入口都正常完成**：本次没有复现，不等于证明问题已修复。负载、引擎版本和驾驶路径变化都可能影响结果。
- **入口情况不同**：继续检查原始日志和隔离差异，不把诊断中的某次胜负直接当作牌力结论。
- **常驻入口回退**：缺少两种独立入口的有效对照，不会把两次原生运行冒充为常驻与原生的比较。

诊断使用当前安装的引擎和当前机器设置。报告记录原引擎信息、当前引擎指纹、牌组文件校验值和参数；如果软件已更新，就不能假定环境与原来完全相同。

## 当前可识别的日志症状

| 症状 | 意义与处理 |
|---|---|
| 模式目标缺少施放者 | Forge AI 在评估目标/费用时出现内部空值；保留日志复现，不能仅凭同桌出现就认定某张牌有问题。 |
| 单次行动选择超时 | 与整局时限不同，可能涉及复杂决策或异常循环；不直接把最后胜者用于可靠的牌力结论。 |
| 无法分配内存 | 先减少同时对局数，检查空闲内存。 |
| 缺少 AI 驾驶逻辑 | 规则上实现了一张牌，不等于 AI 会正确使用。提示本身不改变原始结果分类，也不说明人类使用时较弱。 |

原始日志、正常胜负、超时和错误都保留。异常局不计为正常胜负；未知驾驶逻辑提示不会被伪造为引擎错误。更详细的诊断不能替代规则引擎的实际修复。
