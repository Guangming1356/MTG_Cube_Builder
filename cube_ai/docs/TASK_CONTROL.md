# 暂停、继续与强制结束

运行任务后，页面顶部会出现“任务控制”，切换页面或刷新网页后也能找到。

- **暂停**：停止开始新的工作，等待当前正在进行的对局或计算步骤结束，随后显示“已暂停”。如果同时进行多局，会等待这些已开始的对局结束。
- **继续**：从暂停的位置接着运行，无需重头开始。
- **强制结束**：立即停止这个任务及其 Forge、候选计算子进程。网页和其他任务继续使用。正在进行的比赛不会被当作正常结果。
- **下载记录**：结束的实战任务显示保留的比赛记录数量，可下载已经落盘的记录。牌组、日志和已保存的候选版本仍留在原文件夹。

暂停期间仍会保留任务占用的内存。需要回收资源时使用“强制结束”。强制结束是终止任务；它不提供任意阶段的自动续跑保证。

## 旧后台升级

重新双击助手入口会打开支持任务控制的新版后台，不会在启动时结束旧任务。如果检测到同一项目的旧后台，任务区会单独显示“旧后台任务”。

旧后台无法补装暂停功能；可点击“强制结束旧后台全部任务”。这个按钮会关闭该旧后台及它的全部任务，已保存的文件保留。按钮旁会明确说明范围。新后台的普通“强制结束”仅影响对应任务。

## 验收

- Windows 上每个新任务运行在独立进程组中，包含它产生的 Java 和 Python 子进程。强制结束及后台退出均回收该组；不会按程序名称批量结束其他 Java/Python。
- 真实便携运行环境中完成了 Forge 的暂停、继续、刷新后查找和强制结束检查。
- 暂停等待当前比赛完成后生效；继续后原任务共完成三局。第二个任务强制结束约 0.25 秒返回，保留一条已完成比赛记录；服务和前一任务结果仍可访问。
- 校验了同组子进程被结束、旁边独立测试进程保持运行、排队任务立即结束，以及已有实战暂停时不叠加启动另一轮实战。
- 控制接口沿用本地来源检查；旧后台操作需核对项目、运行环境与进程身份。
