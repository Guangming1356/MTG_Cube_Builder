# Ongoing project goals / 持续项目目标

The Cube assistant is being improved as a usable product, using measured
evidence to prioritize draft and gameplay quality, accessibility, speed,
memory use, and computational efficiency. Keep personal data local and publish
verified releases to the existing public repository.

The current scope also includes:

- A complete and maintainable English/Chinese experience, covering the
  interface, generated results, reports, and repository documentation. English
  is the default for a new installation; preserve a user's chosen language.
  Identify source-language card rules, user-authored material, and any remaining
  machine-translated or untranslated content honestly.
- Adaptable draft rules and useful Commander and high-power Vintage Cube
  workflows. Simulations must apply the rules of the selected format; do not
  report heuristics as measured match outcomes.
- Deck assessment and learning grounded in drafted decks and actual Forge game
  data, with separate validation and transparent limitations. Vintage game
  simulation and automatic learning after standalone drafts remain outstanding.
- Preserve the user's local data, avoid controlling the user's desktop, and
  verify releases before publishing. Do not retain redundant release archives
  on the user's computer.

项目持续优化范围包括中英文界面与报告、可配置轮抽规则、Commander 和
Vintage Cube、基于轮抽与真实 Forge 对局的评估学习，以及速度、内存和界面。
新安装默认英语，已有语言选择应保留。现阶段传统赛制的 Forge 实战与每次
独立轮抽后的自动学习仍未完成，不能将静态评估称为实战结果。
