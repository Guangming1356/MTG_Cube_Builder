构筑参数

先定义体验，再选择卡牌

Commander Bracket 强度目标

Bracket 是组牌后的体验目标。平均单卡评价与 Cube 数量预算属于本项目参数；第 3 档组牌时最多放 3 张 Game Changers，含指挥官与地牌。4/5 档不会自动开启快法术力、无限组合或炸地。

这些参数会直接约束生成结果；角色可以重叠。高级参数中的精确 curve 如非空，将优先使用。

高级参数 · 色组主题 / 曲线 / 轮抓规则

以下 JSON 与上方参数合并。默认三人、10 轮、每包 15 张、每次取 2 张、传过三人后弃余牌，每人获得 60 张。

生成器使用整数规划满足数量、曲线、颜色、互动和终结密度；不满足时会报告失败，不会偷偷放宽条件。
